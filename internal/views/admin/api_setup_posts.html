API Details:

  • Endpoint: {{ .Method }} {{ .BaseURL }}{{ .Path }}
  • Query Parameters:
    • page (integer, default: 1) - Page number
    • per_page (integer, default: 10) - Items per page
  • Response Fields:
    • id - Post ID
    • title - Post title
    • meta_description - SEO description (from excerpt)
    • thumbnail - Featured image URL
    • published_at - Publication date
    • author - Author name
    • tags - Comma-separated tag names

✓ What will be created:

  • • API endpoint in "public" group (no authentication required)
  • • Automatic pagination calculation based on query params
  • • SQL query with LEFT JOINs for related data
  • • JSON response with data envelope

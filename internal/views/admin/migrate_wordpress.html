WordPress Migration

This tool will migrate the first 5 posts and 5 pages from https://adsqoo.id WordPress site.

What will be imported:

  • ✓ 5 posts (type: "post") with HTML content
  • ✓ 5 pages (type: "page") with HTML content
  • ✓ Featured images (stored as URLs, no file download)
  • ✓ Categories and tags (for posts only)
  • ✓ Author information (matched or assigned to current user)
  • ✓ Publication status (draft/publish)

The following records will be created:

  • 5 Page records with type="post"
  • 5 Page records with type="page"
  • Media records for featured images (URL-only, no local files)
  • New categories and tags as needed (if not already in the system)

After Migration

  1. Check the Pages section to see imported content
  2. Review posts and pages — content comes with HTML, may need formatting review
  3. Featured images are linked by URL; they'll display from the original WordPress site
  4. When ready, proceed with phase 2: mount wp-content via Docker volume to serve local copies

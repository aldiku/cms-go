Registrasi SMS Broadcast

Daftarkan Sender ID untuk mulai mengirim SMS Broadcast.

Syarat & Ketentuan

  • Sender ID adalah nama pengirim yang akan tampil di SMS penerima (maksimal 11 karakter, tanpa spasi).
  • Dokumen pendaftaran (form isian, surat kuasa, dsb) diunggah dalam format .zip.
  • Token awal minimum 5.000 kredit SMS untuk memulai.
  • Pendaftaran akan diverifikasi oleh admin sebelum Sender ID aktif digunakan — proses biasanya memakan waktu 1–3 hari kerja.
  • Setelah aktif, saldo dapat ditambah kapan saja melalui menu Topup pada halaman Channel Anda.
